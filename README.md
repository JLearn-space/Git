# Курс «Git и GitHub: за 10 уроков» / "Git and GitHub: in 10 lessons"

> Курс состоит из **10 тем** и посвящён системе контроля версий Git и платформе GitHub — от первой установки и настройки Git до публикации полноценного веб-проекта на GitHub Pages. По завершении обучения студент умеет создавать и вести репозитории, работать с ветками и коммитами, отменять изменения, выполнять слияния, участвовать в командной разработке через Pull Request и публиковать свои проекты.
>
> The course consists of **10 lessons** dedicated to the Git version control system and the GitHub platform — from first installation and Git configuration to publishing a complete web project on GitHub Pages. Upon completion, students can create and maintain repositories, work with branches and commits, undo changes, merge work, collaborate through Pull Requests, and publish their projects.

## Предварительные требования / Prerequisites

Для прохождения этого курса достаточно уметь работать с файлами и папками в терминале (командной строке) и иметь базовые представления о веб-разработке. Курс построен так, что последний урок использует HTML-проект из курса [«HTML: за 10 уроков»](https://github.com/JLearn-space/HTML). Рекомендуется предварительно пройти курсы [«HTML: за 10 уроков»](https://github.com/JLearn-space/HTML) и [«CSS: за 10 уроков»](https://github.com/JLearn-space/CSS), однако первые уроки можно проходить и до них.

To take this course, you only need basic file and folder skills in the terminal (command line) and a basic idea of web development. The course is designed so that the last lesson uses the HTML project from the ["HTML: in 10 lessons"](https://github.com/JLearn-space/HTML) course. Completing the ["HTML: in 10 lessons"](https://github.com/JLearn-space/HTML) and ["CSS: in 10 lessons"](https://github.com/JLearn-space/CSS) courses beforehand is recommended, though the first lessons can be taken before them as well.
