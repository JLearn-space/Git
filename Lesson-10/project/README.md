# Portfolio

Personal portfolio site of **Javlonbek Saydullaev** — web developer.

Built with HTML and CSS, versioned with Git, hosted on GitHub Pages.

## Run locally

Open `index.html` in a browser.

## Publish

1. Create a public repository named `<username>.github.io` on GitHub.
2. Push this folder.
3. Enable **Pages** in repository Settings (deploy from `main`, root folder).
